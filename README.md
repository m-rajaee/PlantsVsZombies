Final Project Of Advanced Programming Class at Isfahan University Of Technology

Developed a multiplayer game using C++ and Qt framework.
Implemented game logic, object-oriented design, and client-server communication between players.
The project involved software design, networking concepts, and building an interactive application from scratch.

How A Match Starts :
Two Clients Connect To A Server
One Client Sends A Request To Another Client To Start The Match. If Another Client Accepts, The Match Starts.
